# 簿記2級 模試メーカー

CPAラーニングの模擬試験（PDF）の**出題パターン**をもとに、毎回ちがう数字の模擬試験を無限に作るアプリです。
問題の作成 → 解答用紙 → 自動採点 → 解説 → **ひっかけポイントの指摘** → 弱点集計 まで、これ1つで完結します。

- 本試験と同じ構成（第1〜3問＝商業簿記、第4〜5問＝工業簿記／100点／合格70点）
- 論点が偏らないよう、直近に出た論点を避けて出題
- 名前ごとに成績・苦手論点を記録（複数人で使える）
- スマホからも解答できる

---

## 1. パソコンで使う

PowerShell を開いて、上から順に打ちます。

```powershell
cd C:\Users\user\MyPython\apri
& C:\Users\user\MyPython\my-ai-app\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt   # 初回だけ
python -m streamlit run app.py
```

ブラウザが開きます。終わるときは PowerShell で `Ctrl + C`。

## 2. スマホ・別のPCから使う

### 方法A：同じWi-Fi内で使う（すぐできる）

1. 上の手順でPCでアプリを起動したまま、PowerShellで自分のIPアドレスを調べる

   ```powershell
   ipconfig | Select-String "IPv4"
   ```

   `192.168.x.x` のような数字が出ます。

2. スマホのブラウザで `http://192.168.x.x:8501` を開く

同じWi-Fiにつながっている必要があり、PCを起動したままにしておく必要があります。
（Windowsのファイアウォールで「アクセスを許可」を聞かれたら許可してください）

### 方法B：ネット上に置いて、どこからでも使う（Streamlit Community Cloud・無料）

1. [github.com](https://github.com) でアカウントを作る（すでにあればスキップ）
2. 新しいリポジトリを作る（Private でOK）
3. このフォルダの中身をアップロードする。PowerShellなら：

   ```powershell
   cd C:\Users\user\MyPython\apri
   git init
   git add .
   git commit -m "簿記2級 模試メーカー"
   git branch -M main
   git remote add origin https://github.com/【自分のID】/【リポジトリ名】.git
   git push -u origin main
   ```

4. [share.streamlit.io](https://share.streamlit.io) にGitHubアカウントでログイン
5. 「New app」→ さきほどのリポジトリを選ぶ →
   Main file path に `app.py` を指定 → Deploy
6. 数分で `https://〇〇.streamlit.app` というURLが発行されます。
   スマホでこのURLを開けば、どこからでも解けます。

> **注意**：Streamlit Cloud では成績ファイルが保存されないことがあります（アプリが再起動すると消える）。
> その場合でも問題を解いて採点することはできます。成績を確実に残したいときは方法Aを使ってください。

## 3. 使いかた

1. 名前を選ぶ／作る（パスワードなし。名前ごとに成績が記録されます）
2. 左のサイドバーで「🆕 新しい模試を作る」
3. 第1問〜第5問のタブを開いて解答用紙に入力
4. 一番下の「✅ 採点する」
5. 点数・正解・解説・**🪤ひっかけポイント**が表示される

サイドバーのオプション：

| 項目 | はたらき |
|---|---|
| 📱 スマホ向け表示 | 仕訳の入力欄を縦に並べる。画面が狭いときオン |
| 出題する大問 | 第1問だけ、工業簿記だけ、などの部分練習 |
| 直近に出た論点を避ける | 同じ論点が続かないようにする（既定でオン） |
| シード | 同じ数字を入れると同じ問題を再現できる（復習用） |

## 4. 出題される内容

| 大問 | 分野 | 論点（ランダムに選ばれる） |
|---|---|---|
| 第1問 20点 | 商業簿記 | 仕訳5題。償却債権取立益／為替予約／資本的支出・修繕引当金／合併・のれん／電子記録債権債務／火災未決算／固定資産の売却（定率法）／売上原価対立法／税効果会計／増資／リース取引／役務収益・役務原価／圧縮記帳／手形の不渡り（全14論点） |
| 第2問 20点 | 商業簿記 | 有価証券（保有目的・評価・売却） または 株主資本等変動計算書 |
| 第3問 20点 | 商業簿記 | 決算整理 →　損益計算書 または 貸借対照表の作成 |
| 第4問 28点 | 工業簿記 | ⑴仕訳3題（材料購入／労務費／製造間接費配賦差異／完成振替／消費価格差異）＋⑵個別原価計算 または 総合原価計算 |
| 第5問 12点 | 工業簿記 | CVP分析 または 直接原価計算 vs 全部原価計算 |

### ひっかけについて

本試験で受験生が実際に落としやすい形を意図的に混ぜています。例：

- 貸倒れが**前期**か**当期**かで貸方科目が変わる
- 合併の対価が純資産を下回れば「のれん」ではなく**負ののれん発生益**
- 固定資産の売却が**期首**か**期中**か（期中なら月割の減価償却が必要）
- リースが**利子込み法**か**利子抜き法**か
- 減損の発生点が**始点（両者負担）**か**終点（完成品のみ負担）**か
- 為替予約が売掛金の**一部だけ**、使わないダミーの相場が混ざる
- 貸倒引当金の**差額補充法**、税効果の「差異×実効税率」

まちがえた欄には「🪤 ひっかけポイント」として、何に引っかかったのかが表示されます。

---

## 5. 採点のルール

- 仕訳：借方・貸方が**両方**合っていれば満点、片方だけなら半分
- 金額欄：完全一致で正解（マイナスの入力が必要な欄には注意書きが出ます）
- 各大問は「正答した配点 ÷ その回の満点 × 本試験の配点」で換算

## 6. ファイル構成

```
app.py               画面（Streamlit）
boki2/core.py        共通の部品（金額表示、解答欄の型）
boki2/q1.py 〜 q5.py  大問ごとの問題ジェネレータ
boki2/exam.py        模試1回分の組み立てと採点
boki2/storage.py     ユーザーごとの成績・出題履歴（boki2_data/）
test_boki2.py        検算テスト（python test_boki2.py）
.streamlit/config.toml  スマホからつなぐための設定
```

## 7. 問題を増やしたいとき

`boki2/q1.py` の `TEMPLATES` リストに関数を1つ足すだけで、第1問の論点が増えます。
関数は次の7つを返す形にしてください。

```
(問題文, 勘定科目6つ, 借方[(科目,金額)], 貸方[(科目,金額)], 解説, 論点名, ひっかけポイント)
```

足したら `python test_boki2.py` を実行すると、貸借が一致しているか等を自動でチェックできます。
